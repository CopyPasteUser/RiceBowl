# Security policy

Please report security issues through GitHub's private vulnerability reporting
feature rather than a public issue. Include a reproducible description and
affected component, but remove credentials, private logs and host identifiers.

MacRice is a user-local XFCE application suite. It does not need to run as root,
and its installer never changes firewall, VPN, network or other system settings.
Configuration backups remain private in the user's home directory.

Only install downloaded releases from the project's repository. If a required
system package is missing, install it through your distribution's package
manager after reviewing the command yourself.
